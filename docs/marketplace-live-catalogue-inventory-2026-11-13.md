## Preview gateway assessment

This public inventory proves product IDs, display names, public categories and active listing status only. It does **not** expose or establish the trustworthiness of each product's private delivery URL, storage object, API origin, tenant model, sample rendition or paid-download boundary.

Accordingly, this snapshot does not certify any product as preview-ready. Keep `previewGatewayVerified` false and keep the release gate closed until an isolated staging Firebase project/database and staging credentials are configured, the admin-only gateway inventory is run against that staging dataset, and each actual delivery target passes its own acceptance tests.

Products that involve regulated or higher-risk subject matter (including gambling, adult-oriented commerce and fireworks) must receive a separate policy and safety review before any preview is considered. This document does not approve them for preview.

## Known catalogue hygiene observations

- Category spellings currently include legacy variants such as “Bussiness Management Systems”, “Ecormmerce Website”, “Retal Property Systems” and “Recuitment Agency Systems”. The public explorer now normalizes whitespace-only duplicates and uses corrected display labels without rewriting the underlying Firebase category values.
- The source catalogue contains both “Restaurant & Catering  Systems” and “Restaurant & Catering Systems”; the public explorer aggregates these under one normalized display category while product filtering still matches both stored values.
