# Marketplace product assets

Store product-specific media and supporting assets here.

Suggested structure:
- `images/` — product thumbnails and gallery images
- `manuals/` — product guides and PDF documentation
- `demos/` — screenshots and demo media
- `metadata/` — product-specific structured data and import manifests

Keep product assets separate from shared site branding, portal assets and application code. Reference assets with stable relative paths from the product catalogue. Do not store secrets, payment credentials, customer data or private API keys in this directory.
