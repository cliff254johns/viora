CarePoint quick help

This is a front-end prototype using browser-local storage for demo records. Use sample data only.

  • Use the left menu or bottom mobile menu to navigate.
  • Add products, search the catalogue, scan barcodes or create a sale.
  • Print a receipt or save it as PDF from the print dialog.
  • Export stock, sales and audit logs as CSV.
  • Change user role from the login screen to preview access levels.

Production requires server-side authentication, a secure database, backups, encryption, tested offline sync, and validated health-system integrations.
